# Security Policy

If you discover a security issue in Codex Mobile, please do not open a public GitHub issue with exploit details.

Email: arshad.asif@live.com

Please include:

- affected version or commit
- impact
- reproduction steps
- any suggested mitigation

Security-sensitive areas in this project include:

- pairing and device auth
- local-network exposure
- whitelist enforcement for project folders
- WebSocket session access
- approval routing
- any handling of Codex or ChatGPT authentication state
